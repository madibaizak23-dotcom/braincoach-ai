# System Context

## Архитектура

```
Telegram Bot
    ↓
n8n Workflows
    ├─ Voice Intake (расшифровка голоса)
    ├─ Classification (определение типа)
    ├─ Qualification Engine (оценка)
    ├─ Offer Engine (генерация предложений)
    └─ Reactivation Engine (переактивация)
    ↓
LLM API (Claude через OpenRouter)
    ↓
PostgreSQL Database
    ↓
Google Sheets (логирование)
```

## Компоненты

### 1. Telegram Bot
- Получает голосовые и текстовые сообщения
- Отправляет ответы и предложения
- Обрабатывает пользовательские реакции

### 2. n8n Workflows
- Оркестрирует интеграции
- Обрабатывает бизнес-логику
- Управляет состоянием пользователей

### 3. LLM (Claude)
- Классификация интентов
- Генерация ответов
- Анализ эмоций

### 4. PostgreSQL
- Источник правды (Source of Truth)
- Хранение всех данных пользователей
- История разговоров

### 5. Google Sheets
- Логирование событий
- Мониторинг метрик
- Ручная проверка данных
