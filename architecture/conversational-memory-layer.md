# Conversational Memory Layer

## Двухуровневая память

### Level 1: Контекст сессии (в памяти n8n)
- Последние 3-5 сообщений текущей сессии
- Текущий интент пользователя
- Контекст предложения

### Level 2: Историческая память (PostgreSQL)
- Вся история разговоров
- История квалификаций
- История предложений и ответов

## Загрузка памяти

1. **Start of workflow** → Загрузить последние 5 сообщений пользователя
2. **Before LLM call** → Добавить контекст в систему
3. **After user response** → Сохранить в PostgreSQL
4. **Cleanup** → Очистить контекст сессии

## Примечание
LLM всегда видит контекст последних 5 сообщений + текущее сообщение.
Это обеспечивает коллерентность разговора без галюцинаций.
