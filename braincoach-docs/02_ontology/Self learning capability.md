# SELF_LEARNING_CAPABILITY

Status: Core Object

Layer: 02_ontology

Type: Capability

---

## Definition

Self Learning Capability — способность человека самостоятельно осваивать новые знания, навыки и задачи без постоянного внешнего управления.

Объект описывает не объем знаний человека, а его способность приобретать новые знания и навыки в изменяющихся условиях.

---

## Core Question

Способен ли человек столкнуться с новой задачей и организовать собственное обучение для её решения?

---

## Scope

Включает:

* самостоятельное освоение знаний
* самостоятельное освоение навыков
* самоорганизацию процесса обучения
* способность переносить опыт между контекстами
* способность выявлять собственные пробелы
* способность строить собственные стратегии обучения

Не включает:

* объем накопленных знаний
* уровень IQ
* оценки
* дипломы
* результаты отдельных экзаменов

---

## Observable Indicators

Признаки наличия:

* начинает без внешнего принуждения
* способен учиться без репетитора
* самостоятельно ищет информацию
* самостоятельно устраняет пробелы
* переносит навыки между областями
* способен осваивать новые среды
* способен самостоятельно принимать учебные решения

Признаки отсутствия:

* начинает только после напоминаний
* зависим от внешнего контроля
* требует постоянных инструкций
* теряется при появлении новой задачи
* быстро прекращает обучение без поддержки
* не переносит навыки между контекстами

## Success Criterion

Объект считается сформированным, если человек способен регулярно осваивать новые знания и навыки без постоянного внешнего управления и сохраняет данную способность при переходе между различными контекстами жизни.
