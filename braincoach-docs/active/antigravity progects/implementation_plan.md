# Implementation Plan - BrainCoach AI Workflow Integrations

This plan outlines the implementation of session resumption for existing clients, user consent tracking for re-engagement, and the design and implementation of the **WF-06: TIMEOUT WATCHDOG** re-engagement workflow.

---

## User Review Required

> [!IMPORTANT]
> **PostgreSQL Schema Updates:**
> To support session resumption and consent tracking, we need to alter the database schema to add the following columns:
> 1. `clients.allow_reminders` (BOOLEAN) - Tracking re-engagement consent.
> 2. `clients.last_nudge_sent_at` (TIMESTAMP) - To prevent spamming inactive users.
> 3. `conversation_state.sub_stage` (VARCHAR) - Micro-stage tracking for granular resumption.
> 4. `conversation_state.pattern_type` (VARCHAR) - Storing cognitive pattern type to maintain context.
>
> Please confirm if these alterations can be run on the database. The proposed SQL statements are in the changes section below.

> [!TIP]
> **Premium Re-engagement Copy:**
> The re-engagement messages generated by Gemini Flash will draw from `followups_master` but will be dynamically styled by the LLM to match the premium cognitive performance coaching brand guidelines (warm, supportive, zero-guilt).

### Component 1: Database Schema

#### [MODIFY] [postgres-schema.md](file:///c:/Users/indir/Vibe-code-projetcs/vs-code-projects/braincoach-ai/schemas/postgres-schema.md)

ADD COLUMN IF NOT EXISTS last_nudge_sent_at TIMESTAMP;

### Component 2: n8n Workflows

#### [MODIFY] [intake-engine-v1-stable.json](file:///c:/Users/indir/Vibe-code-projetcs/vs-code-projects/braincoach-ai/workflows/reference-node-exports/intake-engine-v1-stable.json)
We will modify the core **WF-01: INTAKE** workflow:
1. **UPSERT Node:** Replace the simple query with a Postgres UPSERT node that registers/updates user profiles on telegram message trigger.
2. **Session Recognition & Get State Node:** Retrieve the user's `current_stage` from `clients` and `sub_stage`, `pattern_type` from `conversation_state`.
3. **Branching Node (IF - Active Session?):** 
   - **New Client (or no active session):** Routes to the classification and keyword detection branch to start from scratch.
   - **Old Client (with active session):** Bypasses intake classification and resumes their diagnostic path, routing them directly to `WF-02: QUALIFICATION ENGINE` at their exact step.

#### [NEW] [reactivation-engine.json](file:///c:/Users/indir/Vibe-code-projetcs/vs-code-projects/braincoach-ai/workflows/reactivation-engine.json)
This file represents **WF-06: TIMEOUT WATCHDOG** which executes on a schedule:
1. **Schedule Trigger (Cron):** Runs every hour to check for stuck sessions.
2. **Postgres - Get Stuck Users:** Finds clients with `allow_reminders = true` who have been silent for > 24 hours.
3. **Google Sheets - Load followups_master:** Retrieves templates for warm re-engagement.
4. **Gemini Flash - Generate Premium Nudge:** Dynamically writes a personalized, premium re-engagement text using user data and sheet templates.
5. **Telegram - Send Nudge:** Dispatches the message via Telegram Bot.
6. **Postgres - Update Nudge Timestamp:** Sets `last_nudge_sent_at` to block repeated messages within 24h.
