# Purpose

The Feedback Module transforms audience reactions into new knowledge.

Content is not the end of the process.

Content is a mechanism for observing reality.

The purpose of Feedback is to capture what reality reveals after distribution.

# Responsibility

The Feedback Module:

* collects reactions
* collects observations
* detects signals
* updates registries
* feeds the Research Layer

The Feedback Module does NOT:

* generate content
* redesign assets
* perform distribution

---

# Core Principle


Every asset is an experiment.

Every reaction is data.

Every data point may become a signal.

---


# Control Loop

The Feedback Module is the primary control mechanism of the Factory.

Its purpose is not only to collect reactions.

Its purpose is to measure the gap between expected reality and observed reality.

# Deviation Principle

The most valuable learning does not come from confirmation.

The most valuable learning comes from deviation.

A deviation occurs when reality behaves differently than expected.

Examples:

Expected:

Audience reacts to autonomy.

Actual:

Audience reacts to AI.

Expected:

Parents discuss learning.

Actual:

Parents discuss admissions.

Expected:

High engagement.

Actual:

Low engagement.

Each deviation is a potential source of new knowledge.

---

# Deviation Detection

The Feedback Module should continuously compare:

* expected response
* actual response

Questions:

What did we expect?

What actually happened?

What changed?

What surprised us?

What requires investigation?

---

# Deviation Object

When a significant deviation is detected, the system creates a Deviation Object.

Structure:

{

"difference": "",

}

# Signal Detection

Not every reaction becomes a signal.

The Feedback Module must identify:

* repetition
* anomaly
* acceleration
* persistence

Questions:

Is this recurring?

Is this increasing?

Is this meaningful?

Does it challenge existing understanding?

---

# Output Objects

The Feedback Module may create:


## Observation

A factual observation.

Example:

Parents repeatedly mention AI tutors.

---

## Signal

A potentially important change.

Example:

Growing trust in AI-assisted learning.

---

## Research Candidate

A phenomenon requiring investigation.

Example:

AI Dependency in Learning.

---

## Deviation

A significant difference between expected and actual reality.

Example:

Expected:

Parents react to self-learning.

Actual:

Parents react to AI tools.

Purpose:

Identify model error and trigger investigation.


## Registry Update

Existing knowledge requires updating.

Example:

Phenomenon Registry update.

Season Registry update.
