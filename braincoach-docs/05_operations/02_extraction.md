Status: Active

# Purpose

The Extraction Module transforms a validated knowledge object into an insight package.

The purpose of Extraction is not to create knowledge.

The purpose of Extraction is to reveal the distributable structure already contained within the object.

# Responsibility

The Extraction Module:

* identifies the core observation
* identifies the tension
* identifies the paradox
* identifies the mechanism
* identifies the model

The Extraction Module does NOT:

* perform research
* validate reality
* create hypotheses
* invent explanations

---

# Core Principle

Every strong asset originates from a mechanism.

The purpose of Extraction is to find that mechanism.

---

# Input

Accepted input:

* Signal
* Phenomenon
* Season
* Model

Input must already be validated by Intake.

---

# Observation

What is happening?

Example:

Students spend more time learning than before.

---

# Question

What makes this interesting?

Example:

Why do some students improve faster despite studying less?

---

# Tension

What contradiction exists?

Example:

More information is available.

Learning outcomes do not improve proportionally.

---

# Paradox

What appears true but may be false?

Example:

Access to information does not automatically create learning.

---

# Mechanism

What explains the phenomenon?

Example:

Information consumption is replacing active learning.

---

# Model

What reusable structure explains the mechanism?

Example:

Learning Quality

=

Attention

×

Practice

×

Feedback

# Extraction Rule

The same Insight Package must be usable by:

* Marketing
* Education
* Training
* Products
* Research

Extraction happens once.

Distribution happens many times.

---

# Success Metric

Extraction succeeds when:

* the mechanism becomes visible
* the model becomes reusable
* multiple asset types can be created from the same package
