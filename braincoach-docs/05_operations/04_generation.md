# Content Factory — Generation Module v1.0

Status: Active

Date: 2026-06-05

---

# Purpose

The Generation Module transforms asset blueprints into final assets.

Generation is the execution layer of the Factory.

Knowledge has already been selected.

Meaning has already been extracted.

Packaging has already been designed.

Generation creates the final distributable asset.

---

↓

Feedback

---

# Responsibility

The Generation Module:

* creates final assets
* follows blueprint structure
* preserves meaning
* adapts expression to channel
* applies voice consistency

The Generation Module does NOT:

* perform research
* change mechanisms
* invent new insights
* modify models
* redefine positioning

---

# Core Principle

Generate expression.

Do not generate meaning.

Meaning enters through Knowledge.

Meaning leaves unchanged.

# Meaning Preservation Rule

The following elements must remain unchanged:

* observation
* question
* paradox
* mechanism
* model

Only wording may change.

Meaning must remain stable.

---

# Traceability Rule

Every generated asset must be traceable to:

Knowledge Object

↓

Insight Package

↓

Asset Blueprint

↓

Generated Asset

The Factory must always be able to explain:

Why was this asset created?

---

# Expansion Rule

Generation must support future asset types.

Examples:

* Lesson
* Workshop
* Worksheet
* Presentation
* Consultation Script
* Product Brief
* Offer Brief

Adding a new asset type must not require redesigning the Factory.

Only a new blueprint.

---

# Success Metric

Generation succeeds when:

* assets remain faithful to source knowledge
* assets follow blueprint structure
* assets remain consistent across channels
* production becomes scalable and repeatable
