## Purpose

This domain guide applies TRIZ Contradiction Practice to BrainCoach product, marketing, GPS, content, and research work.

It does not replace the foundation practice.

Use the foundation artifact for rules and templates:

`braincoach-docs/01_foundation/triz_contradiction_practice_v1.md`

## Domain Rule

When a BrainCoach task contains a tradeoff, do not jump to compromise.

First formulate the contradiction:

```text
What do we want to improve?
What worsens when we improve it directly?
What resources already exist?
How can the contradiction be separated?
What stronger option becomes possible?
```

## Current BrainCoach Uses

* GPS value contradiction;
* content vs payment-trigger focus;
* parent control vs child self-control;
* market pain vs mechanism language;
* fast execution vs knowledge quality;
* automation depth vs offer validation.

## Output Requirement

Any TRIZ-guided recommendation must include:

* desired improvement;
* worsening effect;
* contradiction;
* available resources;
* possible separation;
* inventive option;
* expected signal;
* feedback window;
* correction rule.
