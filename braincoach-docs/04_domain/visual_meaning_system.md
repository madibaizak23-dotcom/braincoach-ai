## Decision

BrainCoach adopts a master visual framing layer above individual Visual OS worlds.

Master World:

```text
BRAINCOACH VISUAL MASTER WORLD
Navigation Universe
```

BrainCoach is a Human Development Navigation System.

The audience should repeatedly feel:

* direction;
* trajectory;
* route;
* signals;
* course correction;
* decision support;
* visibility.

This should happen before the audience consciously understands the positioning.

## Relationship To Existing Visual Worlds

Existing visual worlds remain active.

Navigation Universe does not replace them.

It frames them.

```text
Navigation Universe
->
Competitive Trajectory
Architecture
Intelligence
Terrain
Vehicle
Space
Observation
Research
Documentary
```

## Recognition Elements

Most content units should include at least one recurring navigation recognition element.

Examples:

* route;
* path;
* trajectory line;
* checkpoint;
* signal;
* navigation marker;
* direction arrow;
* map;
* coordinates;
* dashboard;
* tracker;
* progress path.

Purpose:

Build subconscious brand recognition without making every post visually identical.

## Visual Diversity Rule

Avoid overusing:

* notebooks;
* desks;
* empty rooms;
* identical parks;
* generic study imagery;
* generic dashboard screens;
* random space metaphors;
* unrelated gaming metaphors.

Research aesthetics remain secondary.

Human trajectories remain primary.

## Weekly Production Planning Rule

Every content week should define:

1. Main Conversation
2. Main Tension
3. Main Question
4. Primary Visual World
5. Master World

Example:

```text
Main Conversation:
We invested so much. What will remain by autumn?

Main Tension:
Parents do not know whether progress is being preserved or slowly disappearing.

Main Question:
What continues without supervision?

Primary Visual World:
Competitive Trajectory

Master World:
Navigation Universe
```

## Agent Rule

Before producing a visual prompt, storyboard, reel scenario, thumbnail, carousel, or story sequence, agents must ask:

1. What is the market pain or phenomenon?
2. What human trajectory is being shown?
3. Which primary visual world fits this piece?
4. Which Navigation Universe recognition element will appear?
5. Does the image still feel like human development, not generic productivity software?

## Boundary

This system does not:

* replace Visual OS;
* replace the 7 Radical Color System;
* introduce new visual worlds;
* ban creativity;
* require every post to look like a map or GPS screen.

It adds visual coherence.

## Practical Formula

```text
Market Pain
->
Human Trajectory
->
Primary Visual World
->
Navigation Recognition Element
->
Brand Coherence
```
