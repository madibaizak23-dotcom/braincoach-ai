# phenomenon_library_master_v2

Status: Draft
Date: 2026-06-04

## Purpose

This file is the unified readable master list of BrainCoach phenomena.
It is a working inventory layer, not the conceptual registry.
The registry defines the structure; this file holds the current phenomenon inventory in a compact markdown table format.

## Table columns

- PH-ID
- Layer
- Title
- Short description
- Observation
- Contradiction
- Question
- Hypothesis
- Mechanism
- World
- Signals
- Status
- Canonical potential

## Layers

- Layer 1 — Formation of the subject.
- Layer 2 — Formation of action.
- Layer 3 — Distortion of measure.
- Layer 4 — Derivative or corrective phenomena.
