## DEC-004

Title:
Transition from Single Object Classification to Multi-Object Impact Analysis

Date:
2026-06-04

Decision:

Knowledge Events may affect multiple Knowledge Objects simultaneously.

The classification model will transition from:

object_type

to

knowledge_objects[]

Reason:

A single commit frequently impacts multiple domains of the Knowledge OS.

Examples:

* Ontology
* Version Registry
* Knowledge Layer

should be represented simultaneously.

Status:

Accepted
