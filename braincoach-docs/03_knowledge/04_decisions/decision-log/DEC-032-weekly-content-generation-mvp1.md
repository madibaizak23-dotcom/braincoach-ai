# DEC-032 Weekly Content Generation MVP-1

Date: 2026-06-18

Status: Accepted

## Decision

BrainCoach proceeds to Weekly Content Generation MVP-1.

The MVP will transform one approved weekly strategy into a multi-channel production package with reels, stories, Threads, Facebook, Telegram, publishing windows, KPI, CTA, visual brief, and signal capture plan.

## Reason

The current manual content process creates bottlenecks:

* research context is split across Perplexity, Claude, ChatGPT, and manual notes;
* reel scripts can take up to 2 hours each;
* stories are created one slide at a time;
* Threads and Facebook receive raw copies instead of adapted content;
* production effort is not fully connected to signal capture and next-week correction.

The first generation MVP should reduce production friction while preserving BrainCoach's research-first logic.

## Rule

One weekly meaning system should produce many channel-native expressions.

The system must not generate disconnected channel content.

Every content unit needs:

* source meaning;
* planned publishing window;
* expected signal;
* KPI;
* CTA;
* channel adaptation;
* review decision.

## Boundary

This decision does not approve autopublishing.

It approves generation of production packages for human review.
