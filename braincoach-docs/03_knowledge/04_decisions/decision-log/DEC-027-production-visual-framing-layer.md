# DEC-027 Production Visual Framing Layer

Date: 2026-06-18

Status: Accepted

## Context

Production OS reviews revealed increasing visual fragmentation risk.

Visual OS can support multiple visual worlds:

* Navigation
* Vehicle
* Terrain
* Architecture
* Intelligence
* Space
* Competitive Trajectory
* Observation
* Research
* Documentary

Without a higher-level framing rule, agents may generate unrelated visual styles:

* notebooks;
* parks;
* dashboards;
* space metaphors;
* gaming metaphors;
* sports imagery.

This creates diversity but weakens brand recognition.

## Decision

BrainCoach adopts:

```text
BRAINCOACH VISUAL MASTER WORLD
Navigation Universe
```

Navigation Universe becomes the umbrella layer above existing visual worlds.

Existing visual worlds remain unchanged.

## Brand Meaning

BrainCoach is a Human Development Navigation System.

The audience should repeatedly experience:

* direction;
* trajectory;
* route;
* signals;
* course correction;
* decision support;
* visibility.

This aligns with:

* Trajectory Intelligence System;
* Human Development Navigation System;
* GPS Model;
* Positioning;
* Visual OS.

## Recognition Elements

Most content units should include at least one recognition element:

* route;
* path;
* trajectory line;
* checkpoint;
* signal;
* navigation marker;
* direction arrow;
* map;
* coordinates;
* dashboard;
* tracker;
* progress path.

## Weekly Planning Rule

Every content week defines:

1. Main Conversation
2. Main Tension
3. Main Question
4. Primary Visual World
5. Master World

Default Master World:

```text
Navigation Universe
```

## Boundary

This decision does not:

* replace Visual OS;
* replace the 7 Radical Color System;
* introduce new visual worlds;
* remove existing visual modes;
* constrain content creativity.

Dashboard and tracker motifs are allowed recognition elements, but they must not turn BrainCoach visuals into generic SaaS productivity imagery.

Human trajectories remain primary.

## Consequences

Agents have a stable visual identity layer for:

* content planning;
* image generation;
* reels;
* stories;
* carousels;
* thumbnails;
* campaign-level visual consistency.

Visual diversity remains available through primary visual worlds.

Brand coherence is preserved through Navigation Universe.
