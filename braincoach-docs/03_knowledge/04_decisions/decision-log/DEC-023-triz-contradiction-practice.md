# DEC-023 - TRIZ Contradiction Practice

Status: Accepted

Date: 2026-06-18

---

## Context

BrainCoach already uses contradiction as an important research and thinking object.

Thinking OS requires contradiction detection.

Goldratt Choice Practice treats conflict as a map of assumptions.

TRIZ adds a disciplined practice for resolving contradictions and generating stronger options instead of accepting weak compromise.

## Decision

BrainCoach adopts TRIZ Contradiction Practice as an active foundation practice.

TRIZ is used to:

* formulate non-standard tasks;
* detect and sharpen contradictions;
* identify resources;
* separate contradictions by time, space, level, role, function, or condition;
* generate stronger options;
* define experiments and feedback.

## Core Rule

A contradiction is a high-value signal.

It should be treated as:

```text
signal of unresolved design
not reason to choose a weak compromise
```

## Consequences

Agents working with contradictions must state:

* desired improvement;
* worsening effect;
* contradiction;
* system level;
* available resources;
* possible separation;
* inventive option;
* expected signal;
* feedback window;
* correction rule.

## Non-Decision

This decision does not change canon.

This decision does not accept new ontology terms.

This decision does not import the full PDF into the repository.

This decision does not approve SQL, embeddings, automation, or workflow changes.
