# DEC-022 - Goldratt Choice Practice

Status: Accepted

Date: 2026-06-18

---

## Context

BrainCoach and its agents frequently need to make choices under uncertainty.

Recent foundation work established:

* Thinking OS as active practice;
* DOTU and Sociology as governed foundation sources;
* anti-noise epistemic hierarchy;
* payment trigger discovery as the current strategic constraint.

Goldratt's "The Choice" provides a useful foundation source for training choice as disciplined clear thinking rather than preference selection.

## Decision

BrainCoach adopts Goldratt Choice Practice as an active foundation practice for humans and agents.

Choice must be treated as disciplined reasoning under constraint:

```text
Goal
↓
Current reality
↓
Constraint
↓
Conflict / contradiction
↓
Assumptions
↓
Invalid assumption
↓
Better option
↓
Reality feedback
```

## Rules

Agents must:

* define the goal before comparing options;
* identify the constraint before recommending action;
* treat conflict as a map of assumptions;
* avoid premature "I know";
* search for win-win options before accepting compromise;
* treat emotions as signals, not final decisions;
* define feedback from reality for every choice.

## Consequences

Choice recommendations must include:

* goal;
* current reality;
* constraint;
* visible options;
* conflict;
* key assumptions;
* weakest / most testable assumption;
* proposed choice;
* expected signal;
* feedback window;
* correction rule.

## Non-Decision

This decision does not change canon.

This decision does not create new ontology terms.

This decision does not import the full book into the repository.

This decision does not approve SQL, embeddings, automation, or workflow changes.
