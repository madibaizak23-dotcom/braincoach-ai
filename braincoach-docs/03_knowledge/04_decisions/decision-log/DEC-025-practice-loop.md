# DEC-025 Practice Loop

Date: 2026-06-18

Status: Accepted

## Context

BrainCoach foundation now includes:

* DOTU / Sociology foundation intake;
* Thinking OS;
* Goldratt / TOC choice practice;
* TRIZ contradiction practice;
* Logic Discipline with ternary logic and Russian Logic as working foundation candidate;
* human adaptation patterns / radicals;
* tracker capture.

These should not remain separate documents.

They need to become the daily operational practice for the founder, clients, marketing, and agents.

The founder has previously studied several source systems, but biological memory cannot keep all operational details active at once.

Tracker should therefore act as external working memory and practical method support.

## Decision

BrainCoach adopts Practice Loop as the operational bridge from tracker input to decision and correction.

BrainCoach also adopts Council Mode inside Practice Loop.

Council Mode uses preserved source methods as active questioning lenses around the founder and clients:

* DOTU for control, goal, environment, feedback, and correction;
* Goldratt / TOC for constraint, conflict, assumption, and choice;
* Altshuller / TRIZ for contradiction and stronger solution generation;
* Lobanov / Russian Logic for terms, quantifiers, premises, conclusion, and indeterminate states;
* DOTU / Sociology for human, cultural, psychic, and social layers;
* adaptation patterns / radicals for support strategy without identity labeling.

The loop:

```text
Raw tracker idea / observation
->
DOTU control frame
->
Current reality and goal vector
->
TOC constraint
->
TRIZ contradiction
->
Logic discipline
->
Adaptation / radical lens
->
Decision or experiment
->
Action
->
Feedback from reality
->
Updated model
```

## Scope

Practice Loop applies to:

* founder self-tracking;
* client tracking;
* marketing analysis;
* offer discovery;
* product decisions;
* agent reasoning.

## Rules

Tracker entries are not only notes.

They are raw material for observation, signal, contradiction, constraint, decision, experiment, and feedback.

Agents must separate:

```text
fact
pattern
inference
hypothesis
decision
feedback
```

Adaptation patterns / radicals are diagnostic lenses, not identity labels.

Logic Discipline must keep three states available:

```text
validated
contradicted
indeterminate
```

## Consequences

BrainCoach practice becomes cyclical:

```text
Observe
->
Interpret
->
Choose
->
Act
->
Measure
->
Correct
```

This loop becomes the practical mechanism for founder growth, client trajectory work, and market learning.

Council Mode makes the tracker a cognitive support system:

```text
memory aid
->
method selector
->
question generator
->
decision support
->
feedback loop
```
