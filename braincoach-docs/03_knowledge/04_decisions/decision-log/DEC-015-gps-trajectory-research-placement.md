# DEC-015 GPS Trajectory Research Placement

## Status

Accepted

## Date

2026-06-12

## Context

The GPS session captured five draft hypotheses:

- GPS-HYP-001 Resonance vs Dissonance
- GPS-HYP-002 Desired State to Current State Gap
- GPS-HYP-003 Personal Boundaries as Trajectory Filter
- GPS-HYP-004 Unified Trajectory Model
- GPS-HYP-005 Fibonacci Lifecycle Hypothesis

The hypotheses are related to existing BrainCoach objects, including Self Learning Capability, External Management Dependency, trajectory assessment, signal validation, Deviation, Contradiction, Case Registry, and age development markers.

The objects are not yet validated enough for Canon, Foundation, accepted Ontology, or Phenomenon Registry.

## Decision

GPS trajectory hypotheses will be placed first in Research.

The current placement is:

- Research: `braincoach-docs/03_knowledge/01_research/gps_trajectory_hypotheses_v1.md`
- Intelligence synthesis: `braincoach-docs/03_knowledge/02_intelligence/gps_trajectory_intelligence_v1.md`
- Ontology candidates: `braincoach-docs/02_ontology/gps_ontology_candidates_v1.md`
- Session capture: `braincoach-docs/03_knowledge/01_research/GPS_SESSION_DISCOVERY.md`
- Discovery report: `braincoach-docs/02_ontology/GPS_ONTOLOGY_DISCOVERY_REPORT.md`

No Canon, Foundation, Phenomenon Registry, or accepted Registry update is approved by this decision.

## Rationale

Research is the correct first layer because the objects are hypotheses, not validated phenomena or accepted ontology terms.

Intelligence is appropriate for synthesis because the hypotheses may form a trajectory layer across existing research.

Ontology candidates are appropriate only as a staging layer because terms such as resonance, dissonance, trajectory_gap, and trajectory_filter still require duplicate checks and validation.

Foundation is not appropriate yet because Foundation should hold stable principles, not fresh session hypotheses.

Canon is not appropriate because the hypotheses are not system-level source of truth.

Phenomenon Registry is not appropriate because the objects are not yet observed phenomena with source signals, experiments, outcomes, and evidence levels.

## Consequences

Future work may reference these files as draft research and draft intelligence.

Future promotion requires:

- observed evidence
- signal links
- duplicate check
- compatibility check with existing ontology
- decision log entry

The GPS trajectory objects must not be treated as canonical until explicitly promoted.
