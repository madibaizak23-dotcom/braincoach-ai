# DEC-020 - Thinking OS As Practice

Status: Accepted

Date: 2026-06-18

---

## Context

BrainCoach Thinking OS v1.0 defines the thinking operators used by BrainCoach agents, humans, and workflows to analyze systems, make decisions, and improve focus.

The document is not meant to become another theoretical artifact.

It should define the actual operating practice of BrainCoach.

## Decision

BrainCoach adopts Thinking OS as an active practice.

Thinking OS is mandatory for serious analysis, especially:

* strategic decisions;
* offer discovery;
* payment trigger discovery;
* GPS positioning;
* production system design;
* content-to-offer work;
* AI-agent reasoning;
* system reviews.

## Practice Rule

No random thinking.

No theory for decoration.

No framework without decision.

Every serious analysis should follow:

```text
DOTU Control Frame
↓
Sociological Context
↓
Constraint Detection
↓
Contradiction Detection
↓
Demand / Payment Trigger
↓
Signal / Phenomenon
↓
Decision
↓
Feedback
```

## Consequences

AI and human analysis must separate:

* observation;
* hypothesis;
* decision;
* canon.

BrainCoach must not optimize non-constraints.

BrainCoach must not convert a mechanism into an offer without checking the payment trigger.

For the current cycle, Thinking OS reinforces:

* current constraint: Payment Trigger Discovery;
* non-constraints: content volume, visual quality, automation depth;
* GPS role: data collection mechanism for a trajectory review;
* offer direction: 14-day Trajectory Review;
* demand question: why would someone pay now?

## Non-Decision

This decision does not add a new repository layer.

This decision does not approve SQL, workflow changes, or new automation.

This decision does not replace Operational Philosophy.

It defines the mandatory thinking practice used inside existing layers.
