# DEC-024 - Logic Discipline Practice

Status: Accepted

Date: 2026-06-18

---

## Context

BrainCoach now has foundation practices for Thinking OS, DOTU/Sociology intake, Goldratt Choice Practice, and TRIZ Contradiction Practice.

These practices require a common logic discipline.

Without logic checks, agents may produce fluent but invalid reasoning.

## Decision

BrainCoach adopts Logic Discipline Practice as an active foundation practice for humans and agents.

BrainCoach preserves Russian Logic as a primary working foundation candidate for formal reasoning and syllogistic analysis, especially where binary true / false treatment is insufficient.

Ternary / three-valued logic is explicitly retained as important source content, not treated as a minor historical note.

Logic Discipline is mandatory before updating:

* foundation;
* ontology candidates;
* knowledge objects;
* GPS interpretation;
* marketing language;
* offer logic;
* strategic decisions.

## Core Rule

No conclusion without valid reasoning.

No inference without premises.

No premise without meaning.

No meaning without boundaries.

No claim stronger than its logical support.

## Agent Requirements

Agents must check:

* term meaning;
* statement;
* premise;
* quantifier / scope;
* inference;
* conclusion;
* contradiction;
* reality feedback.

Agents must label claims as observed fact, source statement, interpretation, inference, hypothesis, validated knowledge, market signal, or decision.

Agents must not collapse unknown, candidate, or indeterminate states into true or false.

Agents must not discard a method because the source uses polemical language.

Polemical source material should be separated into:

* method to preserve;
* source claim to track;
* historical claim to verify separately;
* tone not to import into BrainCoach public language.

## Non-Decision

This decision does not change canon.

This decision does not automatically accept the source's polemical or historical claims as validated BrainCoach knowledge.

It does preserve them as source claims where they affect method, priority, or interpretation.

This decision does not create ontology terms.

This decision does not import the full PDF into the repository.

This decision does not approve SQL, embeddings, automation, or workflow changes.
