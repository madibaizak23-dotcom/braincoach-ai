# ADR-002 — Текущее состояние Cloud SQL, n8n и рабочих баз данных

Статус: APPROVED

Дата: 2026-06-09

## Контекст

В ходе диагностики ошибки:

```text
{"code":503,"message":"Database is not ready!"}
```

была проведена проверка Cloud SQL, Cloud Run и PostgreSQL.

Цель — определить фактический источник проблемы и зафиксировать рабочую архитектуру.

---

## Cloud SQL Instance

Инстанс:

```text
n8n-db-instance
```

Проект:

```text
braincoach-n8n-prod
```

Версия:

```text
PostgreSQL 15
```

Статус:

```text
RUNNABLE
```

---

## Выявленные базы данных

В инстансе обнаружены:

```text
braincoach_dev
braincoach_prod
n8n
n8n_db
n8n_v2_clean
```

## Рабочие базы

### braincoach_dev

Назначение:

Основная рабочая база BrainCoach

Содержит:

* Knowledge OS
* Memory Layer
* Event Registry
* Knowledge Registry
* Content Registry
* Conversation State
* Domain Tables

Исторически использовалась для разработки всей BrainCoach платформы

---

### n8n_v2_clean

Назначение:

База новой установки n8n v2

Содержит:

* workflow_entity
* execution_entity
* credentials_entity
* variables
* users
* webhooks

Проверено:

```sql
SELECT COUNT(*) FROM workflow_entity;
```

Результат:

```text
7 workflows
```

Проверено:

```sql
SELECT COUNT(*) FROM execution_entity;
```

Результат:

```text
331 executions
```

База не пустая.

## Пользователи

### postgres

Системный администратор БД

Используется для:

* администрирования
* диагностики
* создания объектов

Не является владельцем таблиц n8n

---

### n8n_user

Основной пользователь приложений

Владелец большинства объектов:

```text
workflow_entity
execution_entity
credentials_entity
variables
settings
users
```

## Ключевое открытие

Во время диагностики выполнено:

```sql
SELECT usename, application_name, state
FROM pg_stat_activity
WHERE datname='n8n_v2_clean';
```

Получено:

```text
n8n_user | idle
postgres | active
```

Это доказывает:

* Cloud Run подключается к PostgreSQL
* Cloud SQL Connector работает
* пароль корректен
* пользователь корректен
* соединение устанавливается успешно

Следовательно ошибка:

```text
Database is not ready
```

не является доказательством недоступности PostgreSQL.

## Наиболее вероятная причина сбоя

Не база данных.

Вероятные причины:

1. Ошибка конфигурации n8n v2
2. Ошибка task runner внутри n8n
3. Проблема миграции между версиями
4. Ошибка конкретной ревизии Cloud Run

---

## Решение по архитектуре

Сохраняем обе базы:

### braincoach_dev

Source of Truth для BrainCoach OS

### n8n_v2_clean

Source of Truth для n8n

Причины:

* разделение ответственности
* безопасные миграции
* отсутствие риска повредить BrainCoach данные экспериментами с n8n
* возможность независимо обновлять платформу и оркестратор

---

## Правило

Запрещается использовать n8n как хранилище знаний BrainCoach.

n8n хранит:

* workflow
* execution
* credentials
* настройки

BrainCoach хранит:

* knowledge
* memory
* events
* ontology
* registries
* analytics

---

## Итоговое решение

Оставить:

```text
braincoach_dev
n8n_v2_clean
```

как две отдельные рабочие базы внутри одного Cloud SQL инстанса.

Удаление или объединение не требуется.
