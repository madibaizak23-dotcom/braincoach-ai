# Purpose

Function Combinations Registry описывает типовые взаимодействия функций внутри Function Vector Model.

Функции редко работают изолированно.

Большинство устойчивых моделей поведения возникает из сочетаний нескольких функций.

Данный реестр позволяет агентам BrainCoach:

* объяснять наблюдаемое поведение
* выявлять функциональные дефициты
* выбирать компенсирующие механизмы
* формировать сократические вопросы

---

# Combination Categories

## Synergy

Функции усиливают друг друга.

Example:

Direction + Order

---

## Tension

Функции создают внутренний конфликт.

Example:

Energy + Safety

---

## Deficit

Критически важная функция отсутствует.

Example:

Direction + Energy + Order
without
Connection

---

## Compensation

Одна функция частично компенсирует слабость другой.

Example:

High Order compensates Low Energy.

# Functional Gaps

Observation Agent должен искать не только сильные функции.

Основной вопрос:

Какой функции сейчас не хватает?

Example:

Project:

Energy ✓

Direction ✓

Visibility ✓

Order ✗

Interpretation:

Проблема не в мотивации.

Проблема в отсутствии системности.
