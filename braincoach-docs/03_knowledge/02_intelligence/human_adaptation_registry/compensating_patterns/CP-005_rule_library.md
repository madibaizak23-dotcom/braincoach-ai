# CP-005 Rule Library

Pattern ID: CP-005

Pattern Name: Rule Library

Status: Active

Version: v1.0

Layer: Compensating Patterns Registry

Purpose: Convert Experience Into Reusable Behavioral Rules

---

# Purpose

Rule Library является компенсирующим паттерном, предназначенным для превращения опыта в воспроизводимые правила поведения.

Его задача — сократить необходимость постоянного принятия решений через создание заранее сформулированных принципов действия.

---

# Core Principle

Каждая повторяющаяся ошибка может быть преобразована в правило.

Каждый повторяющийся успех может быть преобразован в правило.

* поддерживают долгосрочное развитие

# Why It Exists

В условиях стресса человек редко действует согласно знаниям.

В условиях стресса человек действует согласно встроенным правилам.

Rule Library позволяет сознательно формировать такие правила.

# Trigger Conditions

Agent should consider CP-005 when:

* ошибки повторяются
* решения принимаются заново в одинаковых ситуациях
* человек сталкивается с перегрузкой выбора
* есть успешный опыт, который важно сохранить

---

# Observable Signals

Signals In Favor:

* наличие личных принципов
* последовательность поведения
* быстрое принятие решений
* устойчивость под стрессом

Signals Against:

* повторение одинаковых ошибок
* отсутствие фиксированных принципов
* зависимость от настроения

# Rule Categories

## Identity Rules

Определяют кто я.

Examples:

* Я довожу начатое до конца.
* Я фиксирую наблюдения ежедневно.

---

## Decision Rules

Определяют выбор.

Examples:

* Если данных недостаточно — сначала собираю информацию.
* Если риск необратим — не спешу.

---

## Learning Rules

Определяют обучение.

Examples:

* Ошибка является источником данных.
* Сначала практика, потом выводы.

---

## Performance Rules

Определяют действие.

Examples:

* Если задача не записана — задачи нет.
* Каждый проект начинается с первого артефакта.

---

## Recovery Rules

Определяют восстановление.

Examples:

* После ошибки сначала анализ, потом оценка.
* Один плохой день не отменяет систему.

# Safety Rules

* Не навязывать правила человеку.
* Правила должны приниматься добровольно.
* Любое правило может быть пересмотрено.
* Правила являются инструментом развития, а не контроля.
* Не использовать правила для оценки личности.
