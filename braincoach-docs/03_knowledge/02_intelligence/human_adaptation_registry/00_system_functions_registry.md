# Purpose

System Functions Registry описывает базовые функции человеческой адаптации.

В отличие от Adaptation Patterns, функции не являются характеристиками личности.

Функции представляют собой универсальные механизмы, необходимые для устойчивого развития, обучения, достижения целей и управления изменениями.

Каждая функция может реализовываться различными адаптационными стратегиями.

Adaptation Patterns рассматриваются как наиболее типичные носители соответствующих функций.

---

# Design Principles

## Function First

BrainCoach анализирует не людей, а функции.

Вопрос системы:

Не:

"К какому типу относится человек?"

А:

"Какая функция сейчас помогает развитию?"

и

"Какой функции сейчас не хватает?"

---

## Multi-Function Reality

У одного человека могут одновременно проявляться несколько функций.

Различия между людьми определяются не наличием функций, а их относительной выраженностью, устойчивостью и доступностью.

---

## Dynamic Model

Функции не являются постоянными.

Они могут усиливаться, ослабевать или компенсироваться через внешние инструменты.

# Function Registry

---

## F-01 Energy

Purpose:

Запуск движения и создание импульса к действию.

Primary Pattern:

Hyperthymic

Key Contribution:

Начало процессов.

Failure State:

Нет старта.

Typical Symptoms:

* откладывание запуска
* отсутствие инициативы
* низкая вовлеченность

Core Question:

Что поможет начать движение?

---

## F-02 Understanding

Purpose:

Построение внутренних моделей реальности.

Primary Pattern:

Schizoid

Key Contribution:

Понимание систем и закономерностей.

Failure State:

Действие без понимания.

Typical Symptoms:

* поверхностные решения
* повторяющиеся ошибки
* отсутствие целостной картины

Core Question:

Как это устроено?

---

## F-03 Safety

Purpose:

Управление риском и снижение вероятности критических ошибок.

Primary Pattern:

Anxious

Key Contribution:

Предотвращение угроз.

Failure State:

Игнорирование рисков.

Typical Symptoms:

* необоснованные решения
* недостаточная подготовка
* повторяемые провалы

Core Question:

Что может пойти не так?

---

## F-04 Connection

Purpose:

Поддержание сотрудничества и социальных связей.

Primary Pattern:

Emotive

Key Contribution:

Создание доверия.

Failure State:

Разрушение взаимодействия.

Typical Symptoms:

* конфликты
* изоляция
* потеря поддержки

Core Question:

Как это повлияет на людей?

---

## F-05 Direction

Purpose:

Удержание долгосрочного курса развития.

Primary Pattern:

Paranoid

Key Contribution:

Создание стратегии.

Failure State:

Потеря направления.

Typical Symptoms:

* реактивность
* отсутствие приоритетов
* хаотичное движение

Core Question:

К чему это должно привести?

---

## F-06 Visibility

Purpose:

Делать ценность заметной и понятной другим.

Primary Pattern:

Hysteric

Key Contribution:

Коммуникация ценности.

Failure State:

Невидимый результат.

Typical Symptoms:

* полезная работа остается незамеченной
* отсутствие вовлечения других людей
* низкая поддержка инициатив

Core Question:

Кто должен увидеть эту ценность?

---

## F-07 Order

Purpose:

Превращение деятельности в воспроизводимую систему.

Primary Pattern:

Epileptoid

Key Contribution:

Стабильность и повторяемость результата.

Failure State:

Хаос исполнения.

Typical Symptoms:

* потеря качества
* отсутствие стандартов
* зависимость от случайности

Core Question:

Как сделать это повторяемым?

---

# Functional Diagnosis Logic

BrainCoach не определяет тип личности.

BrainCoach анализирует:

1. Какие функции уже присутствуют.
2. Какие функции перегружены.
3. Какие функции отсутствуют.
4. Какие функции необходимо компенсировать.

---

# Example

Project State:

Energy: High

Understanding: High

Direction: High

Order: Low

Interpretation:

Проект способен запускаться и генерировать идеи, но не способен стабильно доводить их до результата.

Recommended Focus:

Strengthen Order Function.

# Safety Rules

* Не использовать для типирования личности.
* Не использовать как психологическую диагностику.
* Не использовать для прогнозов без наблюдаемых данных.
* Рассматривать функции как рабочие гипотезы.
* Использовать только для улучшения поддержки развития и самостоятельности.
