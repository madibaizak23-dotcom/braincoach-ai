# Purpose

Support Strategy By Function определяет, какой тип поддержки наиболее эффективен для каждой системной функции.

Цель документа — помочь агентам BrainCoach выбирать не советы, а условия, в которых человек сможет лучше использовать собственные ресурсы.

---

# Core Principle

Разные функции требуют разной поддержки.

Одинаковая интервенция может помочь одному человеку и помешать другому.

Поддержка должна усиливать функцию, а не бороться с ней.

# Multi-Function Support

Поддержка выбирается не по одному паттерну.

Поддержка выбирается по сочетанию функций.

Example:

High Energy
High Direction
Low Order

Support Focus:

Order

Not:

More Motivation

# Deficit Logic

Главный вопрос агента:

Какой функции сейчас не хватает для следующего шага?

Не:

Какой паттерн у человека?

# Learning Independence Connection

Самостоятельность растет тогда, когда человек получает поддержку, соответствующую его текущей функциональной конфигурации.

Неправильная поддержка создает сопротивление.

Правильная поддержка создает движение.
