## Purpose

BrainCoach needs logic as a foundation discipline for humans and agents.

Most reasoning errors can be traced to violations of logic:

* unclear terms;
* hidden assumptions;
* invalid inference;
* false equivalence;
* wrong quantifier;
* contradiction ignored;
* opinion treated as proof;
* association treated as causation;
* conclusion stronger than premises allow.

The purpose is not to lose the substance of the source because parts of it sound polemical.

The purpose is to train agents to make reasoning checkable and to preserve the source's methodological claims as working foundation material.

## Source Position To Preserve

The source presents Russian Logic as an engineering / mathematical logic practice, not as rhetorical logic.

Important source claims:

* practical logic grows from engineering tasks and algebra of logic;
* syllogistic reasoning can be represented analytically;
* many everyday and scientific syllogisms do not have transparent solutions in classical syllogistic;
* some syllogistic bases require ternary / three-valued logic;
* the ternary computing tradition associated with Brusentsov and Setun is part of the source's intellectual background;
* truth is not established by majority vote;
* formal and engineering methods of logic can be taught and trained.

BrainCoach does not discard these claims because they are polemical.

BrainCoach preserves them as source claims and working foundation hypotheses to be tested, developed, and applied.

## Russian Logic Working Basis

For BrainCoach, Russian Logic is accepted as the primary working foundation candidate for formal reasoning and syllogistic analysis when:

* a task involves terms, classes, sets, quantifiers, and conclusions;
* ordinary verbal reasoning becomes ambiguous;
* classical informal explanation cannot show why a conclusion follows or does not follow;
* an agent must distinguish valid inference from plausible wording;
* two-valued treatment hides an intermediate or indeterminate state.

If another approach is later shown to solve the same class of tasks more clearly, more generally, or more testably, BrainCoach may compare and update the working basis.

Until then, Russian Logic is treated as the preferred source-grounded foundation candidate for this class of reasoning tasks.

## Ternary Logic Emphasis

Agents must preserve the importance of ternary / three-valued logic in this source.

Ternary logic is not a decorative historical note.

It is part of the proposed solution space for syllogistic and formal reasoning where binary true / false treatment is insufficient.

For BrainCoach, ternary logic should be considered when a reasoning task contains:

* true;
* false;
* unknown / indeterminate / not yet resolved;
* partial inclusion;
* incomplete evidence;
* ambiguous class relation;
* candidate signal not yet validated;
* hypothesis not yet confirmed or rejected.

This maps naturally to BrainCoach statuses:

```text
validated
not validated / contradicted
candidate / indeterminate
```

Agents must not force a binary conclusion when the correct logical state is still indeterminate.

## Core Rule

No conclusion without valid reasoning.

No inference without premises.

No premise without meaning.

No meaning without boundaries.

No claim stronger than its logical support.

If the logic requires a third state, do not collapse it into true or false.

## Logic Before Eloquence

Agents must prefer logical correctness over fluent explanation.

A beautiful explanation with invalid logic is a failed output.

An uncertain but logically marked hypothesis is better than confident incoherence.

## Agent Logic Hierarchy

When checking reasoning, agents must follow:

```text
Term meaning
↓
Statement
↓
Premise
↓
Quantifier / scope
↓
Inference
↓
Conclusion
↓
Contradiction check
↓
Reality feedback
```

## Required Logic Checks

Every serious agent output must pass these checks:

1. Are the key terms defined?
2. Are the terms used consistently?
3. What are the premises?
4. Is any premise hidden?
5. What is the quantifier: all, some, none, one, most, often, maybe?
6. Does the conclusion follow from the premises?
7. Is the conclusion stronger than the premises allow?
8. Is there a contradiction with known facts or accepted BrainCoach objects?
9. Is this a source statement, interpretation, inference, or validated knowledge?
10. What observation could falsify the conclusion?

## Quantifier Discipline

Many errors come from loose quantifiers.

Agents must not silently turn:

```text
some
```

into:

```text
all
```

or:

```text
often
```

into:

```text
always
```

or:

```text
market language
```

into:

```text
reality proof
```

For syllogistic or class reasoning, agents must explicitly check:

* all X are Y;
* no X are Y;
* some X are Y;
* some X are not Y;
* relation unknown / indeterminate.

If the relation is unknown, the output must say unknown.

Unknown is not false.

Unknown is not true.

Unknown is a third logical state requiring more information or a different model.

## Inference Labels

Agents must label claims:

```text
observed fact
source statement
interpretation
inference
hypothesis
validated knowledge
market signal
decision
```

If the label is unclear, the agent must not present the claim as knowledge.

## Common AI Logic Errors

Agents must actively avoid:

* consensus substitution: many people say it, therefore it is true;
* semantic drift: same word used with different meanings;
* category error: mechanism treated as offer, signal treated as phenomenon, opinion treated as outcome;
* quantifier inflation: some becomes all, often becomes always;
* causation leap: sequence treated as cause;
* moralization: process description treated as judgment of a person;
* false dilemma: two visible options treated as all possible options;
* premature synthesis: incompatible ideas blended without resolving contradiction;
* overconfident interpolation: inference presented as source or validated knowledge.
* binary collapse: indeterminate or candidate state forced into true / false.
* majority logic: common opinion treated as valid inference.
* polemic loss: source method ignored because source tone is polemical.

## Relationship To Existing Practices

Thinking OS gives the analysis sequence.

Logic Discipline checks whether each step is valid.

Goldratt Choice Practice structures choices under constraint.

Logic Discipline checks whether the recommended choice follows from the stated goal, constraint, assumptions, and feedback.

TRIZ Contradiction Practice generates stronger options.

Logic Discipline checks whether the contradiction and resolution are formulated without category errors.

DOTU and Sociology Foundation Intake provides source concepts.

Logic Discipline prevents agents from turning source concepts into labels or unsupported claims.

Russian Logic provides a working source foundation for formal reasoning, quantifier discipline, syllogistic analysis, and ternary treatment of indeterminate states.

BrainCoach should develop this foundation through use, examples, and reality feedback rather than flattening it into generic "logic".

## Reality Correspondence

Logic is necessary but not sufficient.

A logically valid model can still fail reality.

Therefore every logical conclusion that affects action must still be tested against:

* observation;
* repeated signal;
* outcome;
* contradiction;
* market response;
* long-term trajectory feedback.

The goal is not logical elegance by itself.

The goal is a more accurate correspondence between BrainCoach representation and reality.
