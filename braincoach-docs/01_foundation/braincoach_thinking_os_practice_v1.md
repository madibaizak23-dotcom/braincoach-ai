## Practice Decision

BrainCoach Thinking OS is not a theory collection.

BrainCoach Thinking OS is our practice.

It defines how BrainCoach humans, AI agents, workflows, and reviews think before they decide.

No random thinking.

No theory for decoration.

No framework without decision.

Every thinking operator must improve at least one of the following:

* clarity of object;
* clarity of goal;
* visibility of deviation;
* identification of constraint;
* detection of signal;
* quality of decision;
* feedback from reality.

If a thinking operator does not improve control, it should not be used.

## Core Practice Formula

Every serious BrainCoach analysis should follow this chain:

```text
DOTU Control Frame
↓
Sociological Context
↓
Constraint Detection
↓
Contradiction Detection
↓
Demand / Payment Trigger
↓
Signal / Phenomenon
↓
Decision

```

## Minimum Analysis Questions

Every serious analysis must answer:

1. What system are we looking at?
2. What is the goal?
3. What is the current state?
4. What is the deviation?
5. What constrains movement?
6. What signal is visible?
7. What decision should follow?
8. What feedback will show whether the decision worked?

## DOTU Control Frame

DOTU is the base language of BrainCoach Thinking OS.

It is used first when analyzing:

* a child;
* a family;
* a team;
* a learning trajectory;
* a marketing funnel;
* BrainCoach itself;
* GPS;
* offer discovery;
* production system;
* education system.

Core question:

```text
What is being controlled, toward what goal, and with what feedback?
```

## Practice Rule For AI

When BrainCoach uses AI for strategic, product, content, research, or architecture work, AI must operate in verification mode:

1. Define the object of control.
2. Define the goal vector.
3. Compare current state against goal.
4. Name the deviation.
5. Identify the current constraint.
6. Separate constraint from non-constraints.
7. Identify contradiction.
8. Check demand / payment trigger when the question touches market, offer, content, GPS, or sales.
9. Name observable signals.
10. State the decision or next experiment.
11. Define feedback from reality.

If the output does not change a decision, experiment, or feedback loop, it is not finished.

## Logic Discipline

Every Thinking OS analysis must pass Logic Discipline.

No conclusion without valid reasoning.

No inference without premises.

No premise without meaning.

No meaning without boundaries.

No claim stronger than its logical support.

Practice artifact:

`braincoach-docs/01_foundation/logic_discipline_practice_v1.md`

Logic Discipline includes ternary treatment of unresolved states.

Agents must not force a binary conclusion when the correct state is:

```text
candidate
unknown
indeterminate
not yet validated
```

Russian Logic is the working foundation candidate for this formal reasoning layer until a stronger proven method is identified.

## Reality Correspondence Rule

The purpose of Thinking OS is not to protect an abstract model.

The purpose is to improve the correspondence between BrainCoach representations and reality.

Agents may reason through missing intermediate steps when the source, foundation frame, and observed reality make the direction clear.

But every such step must be treated as inference until feedback from reality confirms, weakens, or corrects it.

Required distinction:

```text
source statement
↓
foundation interpretation
↓
agent inference
↓
observable signal
↓
decision / experiment
↓
feedback from reality
```

An agent should prefer a useful, explicitly marked hypothesis over vague agreement.

An agent should never present interpolation as canon, accepted ontology, or validated knowledge.

## Anti-AI-Noise Rule

Agents must not confuse statistically common text with truth.

When interpolating or extrapolating, agents must prefer:

```text
observed fact
↓
закономерность
↓
logical / mathematical coherence
↓
source-grounded model with stated measure
↓
feedback from reality
↓
expert interpretation
↓
market language / mass opinion
↓
AI-generated synthesis
```

Mass opinion can be useful as a market signal.

Mass opinion is not proof of reality.

One fact can falsify many opinions.

One stable закономерность can outweigh millions of repeated claims.

Before using a common belief, an agent must ask:

1. Is this reality, or only repeated language?
2. Is this a закономерность, or only a popular explanation?
3. What observable fact could disprove it?
4. Does the inference preserve measure?
5. What feedback from reality should correct the model?
